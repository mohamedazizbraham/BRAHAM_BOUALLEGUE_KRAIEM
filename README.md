# Projet d’évaluation — Interopérabilité en santé

Ce dépôt contient le travail réalisé dans le cadre de l’évaluation d’interopérabilité en santé sur le sujet :

**A — Admission d’un patient**

L’objectif du projet est de concevoir et développer un prototype connecté à un serveur FHIR réel, puis de transformer les données utilisées vers le format cible **HL7 v2**.

## Organisation du dépôt

Le dépôt est organisé en deux parties :

### 1. Travaux individuels

Chaque dossier portant le nom d’un membre du groupe contient son travail individuel :

- `BOUALLEGUE/`
- `BRAHAM/`
- `KRAIEM/`

Dans chaque dossier, vous trouverez :

- `PROMPTS_Nom_Prenom_CdC`  
  Les prompts utilisés pour concevoir et générer le cahier des charges individuel.

- `PROMPTS_Nom_Prenom_realisation`  
  Les prompts utilisés pendant la phase de réalisation, incluant les spécifications, vérifications, tests, corrections et itérations.

- le **cahier des charges individuel** généré à partir des prompts de l’étudiant ;

- le **prototype / code individuel** développé à partir de ses prompts.

L’objectif de cette organisation est de conserver la traçabilité du travail de chaque membre et de montrer la manière dont l’IA a été pilotée, vérifiée et corrigée tout au long du projet.

### 2. Travail commun du groupe

À la racine du dépôt se trouvent les livrables communs et consolidés :

- le **cahier des charges consolidé**, construit à partir des travaux individuels des membres du groupe ;

- le **projet final**, correspondant à la version commune retenue après comparaison, vérification et consolidation des différentes réalisations.
